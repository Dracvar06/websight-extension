WebSight Settings

AI provider

DeepSeek cannot see images or screenshots. Ollama runs entirely on this computer: no quota, no cost, nothing leaves the machine, but answers are slower and need the Ollama app running.

Gemini

Free key from Google AI Studio. Free tier: about 15 questions per minute, 1,500 per day. Stored only on this computer.

Default: gemini-3.5-flash. Older names like gemini-2.5-flash are closed to new accounts; press Test connection to see what your key can use.

DeepSeek

Key from platform.deepseek.com. New accounts get a one-time 5 million token free grant, no card needed. Stored only on this computer.

Default: deepseek-v4-flash (the older deepseek-chat name is retired as of July 24, 2026)

Ollama (local)

Needs the Ollama app running (default address http://localhost:11434). Pull a vision model once in the terminal, for example: ollama pull qwen3.5:9b. Press Test connection to list the models you have installed. If the test says blocked or 403, quit Ollama and start it with: launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"

Voice

Many screen reader users prefer 2x or faster.

Automatic picks a system voice matching the answer's language, which can land on a low-quality one. If the voice sounds bad, choose a specific voice here and use Test voice to preview it. Tip: install nicer system voices under macOS Settings, Accessibility, Spoken Content, then reopen this page.

Whisper large v3 turbo understands every language and detects which one you speak automatically. Free key from console.groq.com: about 2,000 transcriptions per day, no card. Advanced: the address below can point to any OpenAI-compatible Whisper server, including a local one.

Default: whisper-large-v3-turbo

Grant microphone access once here so the hotkey can listen right away.

Keyboard shortcuts

    If a shortcut says NOT ASSIGNED, Chrome dropped it (usually a conflict with another extension or the system). Assign it manually: open chrome://extensions/shortcuts, find WebSight, click the empty box and press the keys you want. On Mac, Alt is the Option key.
